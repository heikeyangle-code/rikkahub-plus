# 现代西洋占星解读模板

本模板供 AI 在拿到 mingli 工具返回的现代西洋占星数据后，作为解读参考。
引擎: NatalEngine(JS) + Caelus(JS) + Astronomy(JS)

本模板是一份写作流程，不是参考手册。
请按以下顺序执行：看完配置数据 → 读 Part 2-3 建立方法论认知 →
按 Part 4 写作流程（步骤0→6）逐句写出 →
用步骤6的防呆清单核验后输出。

## 数据字段地图

【natal 字段——NatalEngine 返回的完整本命盘数据】
natal.sun / natal.moon / natal.rising / natal.midheaven
  - 每个含：{sign, degree, house, isRetrograde, ...}
natal.planets → {mercury, venus, mars, jupiter, saturn, uranus, neptune, pluto}
  - 每个含：{sign, degree, house, retrograde, dignity, ...}
natal.nodes → {northNode, southNode} / natal.lilith / natal.chiron
natal.houses → [12个宫位，每宫含 sign/houses(跨宫)]
natal.aspects[] → 全盘相位列表（每相位含 planet1/planet2/aspect/orb）
natal.aspectsByPlanet → 每颗行星的相位聚合
natal.elements → {fire, earth, air, water, total} 元素分布
natal.signs → 各星座分布计数
natal.bigThree → {sun, moon, rising} 简写（删除以省体积，可用 natals 字段获取）

【caelus 字段——Caelus引擎计算的深度技法】
（caelus 已按源码模块分组：chart / bodies / events / progressions / transits / harmonics / astrocartography）

caelus.chart — 本命盘基础：
  signature → Caelus.chartSignature() 星盘指纹
  elementBalance → {Fire, Earth, Air, Water} 元素量化分布
  patterns → Caelus.detectPatterns() 星盘图形模式
    （碗型/提桶/跷跷板/散落/集团/火车头等）
  lots → Caelus.lots() 阿拉伯点（福点/精神点/需要点等）
  isDay → 日生/夜生 布尔值
  chartBrief → Caelus.chartBrief() 简要特征摘要
  housesWholeSign → 整宫制宫位
  cusps → Placidus 宫头
  vertex / eastPoint → 敏感轴点
  planetHouses → {planet: house} 每星落宫
  aspects → 宫相位列表
  planetDignities → {planet: dignity} 每星尊贵信息

caelus.bodies — 行星深度分析（本命出生时刻）：
  dignityScores → {planet: score} 尊贵度评分
  dignityOf → {planet: {domicile/exalt/...}} 入庙/擢升等具体状态
  pheno → {planet: {phase, speed, ...}} 行星现象（速度/光照状态）
  oob → {planet: {outOfBounds, margin}} 越界检查（全10星）
  midpoints → {sunMoon, ascMc, sunAsc, moonAsc} 中点
  solarPhase → {planet: phase} 太阳相位（晨升/夕升/晨降/夕降等）
  antiscionSun/Moon / contraAntiscionSun/Moon → 映点/反映点
  birthPlanetaryHour → 出生时辰星（start/end 已转 UTC 日期）
  almuten → Almuten Figuris
  natalDeclinationAspects → 赤纬相位（本命，出相位/入相位）
  starConjunctions → 恒星合相（0.5°容许度，2.5星等以内）
  chiron → {lon, sign} 凯龙星位置
  natalVoidOfCourse → 月亮空亡状态（本命出生时刻；signExit/nextAspect 已转 UTC 日期）

caelus.events — 天象事件（未来窗口）：
  lunarPhases → 月相（30天8相位）
  eclipses → {solar[], lunar[]} 未来半年日月食
  crossings → {planet: [...]} 行星换座时间（未来90天）
  stations → {planet: [...]} 行星留（90天内）
  riseSet → {sun: {rise, set}, moon: {rise, set}} 出生后首次日月升降

caelus.progressions — 推运：
  firdaria → 法达大运（日生/夜生对应）
  profections → 小限（当前年度+月度）
  solarArc → 太阳弧推运（当前）
  progressedMoon/Sun/Other → 次级推运（推至当前年龄）
  primaryDirections → 主限推运
  solarReturn → 太阳返照盘（未来3年）
  lunarReturn → 月亮返照盘（未来3个月）

caelus.transits — 行运（当前时刻）：
  transits → 行运方位相位
  transitPositions → 当前行运行星位置（全13星含凯龙）

caelus.harmonics — 调和盘：
  harmonicChart → 5倍频调和盘

caelus.astrocartography — 简版占星地图（±60°纬度）

【synastry 字段】（可选，传 partner_year 等参数时触发）
NatalEngine.compareAstrology() 的合盘比较结果
包含双方行星位置比较、相位、宫位互落等

## 流派与方法论边界（必读）

本模板属于**现代心理/人本主义占星**（Modern Psychological / Humanistic Astrology）：
热带黄道 + Placidus 宫位（整宫制仅作参考）、现代十行星+凯龙+南北交点、
现代相位容许度（按 Sue Tompkins 体系）。核心方法论见第三部分五位作者。

【古典字段边界——重要】
路由为深度与交叉验证，同时返回了一批**古典/传统技法字段**，它们不属于现代
心理占星体系，解读时必须按**古典含义**（Valens/Ptolemy 体系）处理，严禁套用
心理占星框架（例如不得用 Greene 的原型/阴影语言解释法达或主限）：

  caelus.chart：lots(阿拉伯点)、isDay(日生/夜生Sect)、planetDignities(尊贵)
  caelus.bodies：dignityScores/dignityOf(五级尊贵)、pheno(行星速度/光照现象)、
                 solarPhase(日核/灼伤/光束下)、antiscion*/contraAntiscion*(映点/反映点)、
                 birthPlanetaryHour(出生时主星)、almuten(Almuten Figuris)、
                 natalVoidOfCourse(本命空亡)
  caelus.events：riseSet(出生后首次日月升降，服务于Sect/时主星)
  caelus.progressions：firdaria(法达)、profections(小限)、primaryDirections(主限)

【解读规则】
1. 心理字段用心理语言，古典字段用古典语言，两者不混用。
2. 古典字段在现代解读中默认降权：优先用现代字段支撑结论，古典字段只作
   "古典补充/交叉参考"，不可作为现代解读的主要依据。
3. 若对某古典字段含义不确定，宁可不用，禁止臆测性解释。
4. 想要纯古典解读（法达/主限/小限/尊贵等），应调用"传统西洋占星"或
   "深度古典占星"路由，本路由不承担古典预测体系的主输出。

【精准解读铁律（调研补充，按 Tompkins/Arroyo/Greene 权威实践）】
1. **Top Factor 优先**（Arroyo"最少可靠因子"原则）：动笔前先在内部锁定
   高权重因子——日月升、角宫行星、紧密相位、图形模式、角点合相；
   其余字段只作展开佐证，禁止47字段平铺式解读。
2. **容许度按第六部分表格执行**（合冲：日月10°/金水火8°/土木天海冥6°；
   其他：日月8°/金水火6°/土木天海冥4-5°），越接近0°权重越高；
   超出容许度的相位不得作为证据。
3. **现代占星禁止事件断言**：只输出心理动力、趋势与选择空间；
   行运/推运读作"当下原型能量的表达"，不得写成"某年某月会发生X"。
4. **逆行/停滞规则**（Tompkins）：逆行=能量内化——水逆重思、金逆内省
   关系价值、火逆内驱、木逆内省信念、土逆内观责任、外行星逆为世代主题
   内化；停滞(Station)=该主题进入显意识聚焦期。
5. **强结论门槛**：同一主题至少2个独立高权重指标（如紧密相位+宫位/主宰星/
   图形模式）同时支持，才允许"强烈/确定"级表述，否则用"倾向/可能"。

## 第三部分：五位作者的方法论详解

### ① Dane Rudhyar（奠基人，1936-1980s）

**核心著作**：《The Astrology of Personality》（1936）、
《Person-Centered Astrology》（1972）

**核心方法——四步循环法（整体→部分→综合→整体）**：
1. **将星盘作为整体感知**——不判断好坏，先"感受"整体图形。
   星盘是曼陀罗(mandala)，不是零件清单。
2. **逐一检查组件功能**——两轴、12宫、12星座、行星、相位。
   每个因子的意义从两方面理解：与整体的关系（参照系）+ 在循环中的位置
   （与其他部分的关系）。
3. **逐步综合**——将各部分分析整合。
4. **再次作为整体感知**——但这次带着对互动关系的深度理解。

**种子模式(seed pattern)**：星盘不是命运判决，而是"这个人的潜在地图"。
星盘里没有好配置/坏配置——"The birth-chart is not something to be judged
as good or bad; it is approached aesthetically and holistically."

**在你的解读中**：始终先给人格整体印象，禁止从技术细节开场。

### ② Stephen Arroyo（能量语言，1970s-1990s）

**核心著作**：《Astrology, Psychology, and the Four Elements》、
《Chart Interpretation Handbook》、《Astrology, Karma & Transformation》

**核心方法——四大元素作为能量词汇**：
- 火（热忱/活力/自信）、风（智性/社交/客观）、水（情绪/直觉/共情）、
  土（务实/稳定/物质）
- 主动元素（火+风）向外表达，被动元素（水+土）向内收敛

**核心原则——Major Life Themes**：
Arroyo 在《Chart Interpretation Handbook》第9章明确写道：有效的解读核心
是"tuning into, understanding, and then illuminating the major life themes
of the individual"。使用的因子越少越好——"using a minimum of major
reliable factors to see the client clearly, rather than projecting
confusion."

**三步翻译法（行星→术语→体验）**：
行星落宫 = "这个人哪个领域最用力"；行星落座 = "以什么风格做"；
行星相位 = "内在如何合作或打架"。

**在你的解读中**：每句术语必须附翻译。不是"月土刑"，而是"你在表达快乐的
时候总是带着一种不敢完全投入的谨慎"。

### ③ Liz Greene（深度心理学，1976-今）

**核心著作**：《Saturn: A New Look at an Old Devil》（1976）、
《The Astrology of Fate》（1984）、
《The Astrological Neptune and the Quest for Redemption》（1996）

**核心方法——六步流程**：

**第一步：技术框架清查（Essential Dignities + Sect + Angularity）**
Greene 不是"只看心理不看技术"的。她的第一步永远是对古典条件的完整评估
——入庙(domicile)、擢升(exaltation)、落陷(detriment)、失势(fall)、
昼夜 sect（日生/夜生图）、角宫强度。这不是"算命"的吉凶判断，而是判断
这个 archetypal energy 的表达条件：入庙的行星表达流畅自然，落陷/失势的
行星需要意识化的努力来建设性地表达。

原书示例："Saturn in domicile (Capricorn or Aquarius) signals resilience
and sober strength. Saturn in detriment (Cancer) or fall (Aries) depicts
anxieties about authority that call for ethical maturation, not fatalism."

在你的解读中：虽然你不写出"入庙/落陷"这些术语，但在内部必须做这个评估
——因为它决定了你在写土星/火星/金星时用"自信流畅"还是"需要意识化努力"
的语气。

**第二步：识别核心行星复合体(Planetary Complexes)**
找到2-3个锚定整张盘的配置。比如月土刑不是"一个不好的相位"，而是整张盘的
人格组织中心之一。

**第三步：相位作为原型对话**
相位不是"这个三分相好、那个四分相差"——相位是人格内部不同力量之间的对话。
合相=融合，对冲=对立拉扯但必须共存，四分=成长张力的来源，三分=天赋自然
流动的通道。

**第四步：行星的三段式解读——Greene 的核心套路**
这是 Greene 原书中反复出现的解读结构。以《Saturn》中 Saturn in Aries
的实际原文为例：

> "Saturn is in his fall in Aries"（先给技术条件）
>
> "Possibly the most difficult side is the tendency to be cut off from
> both the flow of outer life and the flow of inner life, so that the
> individual is stranded in a very small and very arid area of his psyche"
> （再给核心心理动态：两层阻断）
>
> 然后呈现**两个无意识极端**：
> 极端A——"The person who perpetually effaces themselves to avoid a
> struggle... there is often great emphasis on being 'unselfish'. But to
> be unselfish one must first have a self to give away."
> 极端B——"No one is more outgoing than they. No one more prepared to take
> charge or seize control. Their philosophy is 'the best defense is
> offense'."
>
> 最后给意识化方向——"The use of will is something available to every
> human being, but it grows in proportion to one's self-knowledge and
> self-mastery."

**三段式公式（可直接用于你的写作）：**

技术条件 → [入庙/落陷/失势，决定语气强度]
核心心理动态 → [这个配置在无意识层面的核心运作模式]
两个无意识极端 → [未意识化时两种截然不同的表面表达，看似相反实则同源]
意识化方向 → ["当当事人看清这个模式后，可以转化为什么"]

同样的结构可见于 Saturn in 10th 的解读：

> "Saturn is dignified in Capricorn and the tenth house"（技术条件）
>
> "He coincides with limitations, delays, and difficulties in achievement
> of one's goals, as well as intense ambition—frequently unconscious—and
> a determination to succeed whatever the cost."
> （核心动态：表面是limitation，里面是intense ambition）
>
> "The tenth house with its occupants and its ruler is one of the best
> pointers not to the actual work, but to the **inner goal or meaning of
> that work** from the point of view of both the individual and society."
> （意识化方向：表面是职业，里面是内在目标）

注意 Greene 的方法**不是"这个配置好/差"的二分法**。她永远在追问：
这个配置在无意识层面怎么运作？它的两个极端表达分别是什么？意识化的方向
在哪里？

**第五步：神话放大(Mythic Amplification)**
Greene 的标志性技术。使用神话、童话、文学作品中的原型意象来"放大"行星
含义。例如 Saturn 对应 Kronos（时间与律法）、Pluto 对应 Hades/Persephone、
Neptune 对应奥德赛中的航海者。

方法：先完成技术分析（第一步-第三步），再引入恰当的神话意象。神话是提供
理解框架的启发式工具(heuristic mirror)，不是替代技术分析。

**第六步：经运作为"意义生成时刻"**
经运不是预测"会发生什么"，而是 archetypal potential 在寻求表达的"季节"
——它们是"kairos for meaning-making"，是提示"需要关注这个领域"的信号。

**在你的解读中**：Greene 的六步法中，第一步（技术清查）和第四步（三段式
解读结构）是最容易被忽略的。前者是技术根基，后者是她真正的写作方法论
核心。

**扩展维度——Greene 的命运-选择框架（来自《The Astrology of Fate》）**：
Greene 的第二本核心著作提供了一个与 Saturn 方法互补的框架——命运(fate)
与自由意志(free will)不是对立的，而是交织的(co-extensive)。这个框架在
处理外行星（Pluto、Neptune、Uranus）和困难经运时尤其关键。

核心概念：
1. **命运不是"预定"，而是"展开"(unfoldment)**："an unfoldment of natural
   processes rather than predestined or preordained events."——星盘不是
   判决书，而是自然过程的展开图谱。
2. **Moira（命运三女神）作为宇宙秩序**：Clotho 编织生命线、Lachesis 度量
   长度、Atropos 剪断——命运对应的是 natural law（自然法则），不是随机
   的惩罚。最严重的"罪"是 hubris（傲慢）——超越自然界限的狂妄。
3. **Pluto = "must be accepted"而非"must be fixed"**：Greene 对 Pluto
   的解读独树一帜——"Pluto represents that which must be accepted—
   violence, chaos, desire—not changed or 'healed.' Acceptance of what
   cannot be changed is often the key to real change." Pluto 的宫位指示了
   "选择不再可用"的领域，"one is subject to something far greater than
   personal will or choice"。
4. **命运与个人责任的悖论**：Greene 坚持承认命运(call it fate, call it
   Moira)不会消解个人责任——恰恰相反，"This acknowledgment of fate does
   not diminish personal responsibility; rather, it empowers individuals
   to recognize their choices within the cosmic narrative."

在你的解读中的应用：
- **当遇到 Pluto/8宫/天蝎强化的盘**：不要用"转化/疗愈"的语言去包装——
  Pluto 的领域是"必须接受的"，不是"可以被修复的"。困难经运的 Pluto 过境：
  读为"这个领域的选择权暂时不在了，唯一的选择是态度——如何接受这个不可
  改变的事实本身"。
- **当盘面出现矛盾且无法统一时**：这个矛盾可能就是 Moira（命运织布上的
  经纬线）——不是技术失误，而是命主真实生命经验的一部分。允许矛盾留在
  解读里，不要强行统一。
- **经运不是"好事/坏事"**：经运揭示的是自然法则(natural law)的运作周期
  ——"cosmic alignments illuminate specific areas of our lives, prompting
  us to confront unresolved issues or seize new opportunities."

### ④ Howard Sasportas（宫位心理学，1985-1990s）

**核心著作**：《The Twelve Houses》（1985，2007修订版）

**核心方法——宫位作为人格发展序列**：

Sasportas 将12宫分为四个象限，每个象限对应一个发展阶段：

第一象限（1-3宫）：建立独立身份。1宫=感知世界的镜头，2宫=将自我与母体
区分（身体-自我），3宫=心智从身体中分化（心智-自我）。

第二象限（4-6宫）：精炼身份。4宫=自省意识的诞生，5宫=独特性表达，
6宫=内在与外在的对应关系。

第三象限（7-9宫）：重新连接他人与世界。7宫="我"回归"非我"，
8宫=关系作为改变催化剂（Greene 补充："将死亡与遗产那种粗浅的解释是对
8宫复杂性的侮辱"），9宫=将生命理解为旅程。

第四象限（10-12宫）：超越自我。10宫=融入社会，11宫=超越自我认同，
12宫=回归原始统一。

Sasportas 原话："We emerge out of the universal matrix of life, establish
ourselves as individual entities, and then find after all we are really
one with all creation."

原书结尾："Why don't you become what only you can become?"

**在你的解读中**：一个行星在5宫不仅仅是"这个行星管理恋爱和创造"——它
意味着"这个人正处于通过创造性和愉悦来表达独特性的发展阶段"。宫位不是
"事件盒子"，是发展舞台。

### ⑤ Sue Tompkins（教学体系，1990s-今）

**核心著作**：《The Contemporary Astrologer's Handbook》（LSA教材）、
《Aspects in Astrology》

**核心方法——相位作为"活力之源"**：
Tompkins 在《Aspects in Astrology》中写道，相位提供了星盘的"prima
materia"（原始素材）——"aspects provide the energy in the chart that
transforms it from a lifeless puppet into something symbolising an alive
and vital human being, complete with conflict and joy."

**行星组合优先**：她的"行星食谱"部分不按具体相位类型区分，而是按行星
组合讨论（如月-土、金-火）。她承认每种"预置解读"都是 caricature（漫画式
简化），真实解读需要读者创造性独立工作。

**角点(angles)的重要性**：Tompkins 在书第三部分专门讨论行星与四轴点
（ASC/DSC/MC/IC）合相——角点力量压倒一切。

**Tompkins 在你的解读中**：校验技术参数的精确性（容许度、相位计数）；
同时提醒你——任何"食谱式"的解读都只是起点，真实的解读需要你独立创造。

**五位作者之外的另一个声音——Greene 的警告**：在《Saturn》引言中，
Greene 写道——"There is no fast and easy method of making a friend of
Saturn." 这个警告适用于整个占星解读。五位作者的方法论是为你提供结构和
工具，不是捷径。当你面对一张星盘不确定如何落笔时，宁可少写一句确实的话，
也不要多写一句不确定的话。

## 第四部分：写作流程（按顺序执行）

### 步骤0：先做技术分析（在内部完成，不写）

1. 要素清查：命主星+太阳+月亮的位置 + 入庙/落陷/角宫/昼夜 sect 评估
   （Greene 第一步）
2. 确认最强相位网（Tompkins 标准：3°以内尤其重要）
3. 用 Sasportas 模型确认行星所在的宫位处于什么发展阶段
4. 确认当前经运/推运激活的信号
5. 做 Arroyo 收缩：从以上所有信号中选出2-4个 major life themes
6. 问自己：哪些信号是主线级别的？哪些只是细节？——不是为了"全面"就
   什么都写

### 步骤1：输出排盘核心数据

用两个表格列出：第一行上升+日月水金火，第二行木土天顶+命主星
（含入庙/落陷状态）。
下方单列核心相位（最紧的3-5个）。
完整排盘数据 mingli 工具已经返回了，不需要在正文里全部罗列。

### 步骤2：写开篇 · 核心叙事（约30%）

**方法（Rudhyar 整体优先 + Sasportas 宫位序列 + Greene 原型对话 +
Arroyo 能量语言）：**

1. **看完盘先问自己——"如果你只能用一句话描述这个人，你会用哪句话？"**
   这就是开篇第一句。然后反推：这句话的依据来自哪些配置？依次补上
   证据链。
2. **命主星+太阳+月亮必须同时出场**，展示三者之间的呼应或张力。
   这是 Greene 强调的："No interpretation of Saturn... can be complete
   without synthesising Sun, Moon, and Ascendant first."
3. **在开篇中就点出最大的矛盾/张力**。张力=核心叙事。禁止在开篇末尾
   说"其实也有冲突"——冲突就是开篇本身。
4. **不要默认套用"阴影功课"语言给所有困难相位**。Greene 的方法不是把
   每个困难相位都写成"阴影需要面对"，而是让人看到：这个张力的存在本身
   就同时包含痛苦和超越的可能性。

公式：

"你是一个[整体人格描述]的人。
上升[星座]让你[外在风格——来自 Sasportas 1宫: 感知世界的镜头]。
但内在，[太阳位置]让你渴望[核心追求]，而[月亮位置]让你需要[情感需求]
——这两者之间的[具体张力——来自 Greene: 原型对话]是你最核心的人生课题。
这不是矛盾，而是一对需要终生对话的力量。"

### 步骤3：写中段 · 主题展开（约40%）

**方法（Arroyo major life themes + Greene 原型对话 + Tompkins 行星组合
+ Sasportas 宫位弧）：**

1. 确定2-4条核心主线。注意：**如果你在步骤0选出了3个 major life themes，
   这里就不应该出现第4个**。Arroyo 说"最少的主要可靠因子"——宁可少，
   不要杂。

2. **每条主线跨越多颗行星+多个相位+宫位**。禁止按"太阳→月亮→水星→
   金星……"罗列。例如"信任与安全"这条线同时涉及月亮天蝎、土星相位、
   4宫配置——必须在一段里讲完。

3. **Greene 的三段式主线公式**（来自《Saturn》原文的实际结构——先读
   技术条件，再呈现两个无意识极端，再说意识化方向）：

   技术条件 → [这个位置/相位的入庙/落陷/角宫状态——决定语气强度]
   核心动态 → [两股力量在原型层面的核心对话]
   无意识极端A → [未被看见时的一种表面表达]
   无意识极端B → [同一个来源的相反表面表达]
   意识化方向 → [当看清这个模式后的转化可能；不是"会好的"，
     而是"有另一种可能性"]

   注意：**不是每个配置都必须同时写极端A和极端B**。Greene 的做法是在
   有显著张力时呈现两极，在相对整合的配置中直接说核心动态。判断标准：
   这个配置在 step 0 的技术清查中评估为"落陷/失势/强刑冲" → 用三段式；
   评估为"入庙/擢升" → 直接说核心动态。

4. **矛盾信号在段落内部保留张力，禁止强行统一**。不是"虽然有困难但也有
   优点"那种二元平衡，而是"这个配置同时包含痛苦和超越的可能性"
   （Greene 方法）。

5. **如果有行星在角点附近（ASC/DSC/MC/IC），优先在主线中提到**
   （Tompkins 强调角点压倒一切）。

6. **Tompkins 自省提醒——你的解读是 caricature**：Tompkins 在
   《Aspects in Astrology》中明确警告——任何"预置解读"都是 caricature
   （漫画式简化），"often ugly distortions meant to provoke thought
   rather than serve as definitive interpretations." 本模板提供的所有
   公式（三段式公式、开篇模板、中段结构）都只是起点。真实的解读需要
   你独立创造——"soften the text where trines and sextiles are
   concerned"，不要生硬套公式。

### 步骤4：写纵深 · 时间维度（约20%）

**方法（Greene 经运作为"kairos for meaning-making" + Greene Fate 框架
+ Rudhyar 种子生长）：**

1. 只写当前真正激活的推运/经运。没有数据就别写。
2. 经运不是"坏事要来了"——是"这个 archetypal potential 正在寻求表达"
   （Greene 方法论）。
3. 如果当前经运涉及土星/外行星，用 Greene 的框架（Saturn = 个体化进程中
   的心理过程）。
4. **如果经运涉及 Pluto（或显现为命运级别的事件）**：使用 Greene 在
   《The Astrology of Fate》中的框架——Pluto 的领域是"must be accepted"
   而非"must be fixed"。不要用"转化""疗愈"去包装 Pluto 过境，而是读为
   "这个领域有一件事让你清楚地看到了自己意志的边界；接受这个不可改变的
   事实本身，就是转变的开始"。
5. **如果盘面呈现的矛盾在理性层面无法统一**：允许这个矛盾留在解读中，
   不强行统一。Moira（命运织布上的经纬线）可能在编织一条超越理性的叙事。
6. **将经运挂靠在已确立的 main themes 上**——开篇有3条主线，时间维度
   不应该出现第4条新主题。

### 步骤5：写收束 · 行动总结（约10%）

1. 成长建议是对前文核心张力的延续，不是新建议。
2. 落点始终是"选择"与"意识化"——不是告诉你该怎么做，而是帮你看到你
   有哪些选择。
3. 最后一句固定格式：「这段时间里，这张命盘最想让你看清的一件事：
   ______」。

### 步骤6：输出前核验精度防呆清单

写完后逐条检查。满足任何一条不通过 → 修改后再输出：

1. **[结论可回溯]** 每一句"你是一个……的人"或"你如何如何"的判断，后面
   是否隐含了"从配置上看……"的证据支撑？禁止无源结论。这条是防止 AI
   编造听起来深刻但无盘面依据的描述。

2. **[术语翻译]** 每出现一个占星术语（月亮天蝎、月土刑、命主星等），
   有没有紧接着"也就是说……"的体验化翻译？Arroyo 体系里，术语不翻译
   等同于无效输出。

3. **[中段结构]** 中段是按"太阳→月亮→水星→金星……"逐个报配置的，
   还是按主题线组织的？如果是前者 → 重写。主题线是 Arroyo 和 Greene
   共识：星盘解读不是配置清单。

4. **[困难相位语气]** 是否用了"导致/带来/造成X不幸"来描述困难相位？
   如果是 → 改。Greene 的框架里，困难相位不是"厄运"，它描述的是需要
   被意识化的内在张力。

5. **[二元平衡陷阱]** 整体结构是否落入了"虽然A有困难但也有B的优点"
   这种简单二元平衡？好的解读应该是"这个配置本身就同时包含着痛苦和
   超越的可能性，两者不是对立的"。

6. **[经运不是预测]** 推运/经运部分是否被写成了"坏事要来了"或"好事要
   来了"？如果是 → 改。Greene 框架下经运是"某个 archetypal potential
   正在寻求表达，是意义生成的时机(kairos)"。

7. **[一句话核心叙事]** 全文是否能用一句话说清这个人最核心的生命课题？
   如果不能 → 回到步骤0重新做 Arroyo 收缩，说明开篇前的收敛不够好。

8. **[Silence on uncertainty]** 某个配置的具体含义你不确定、或者原型对话
   关系不清晰时 → 宁可跳过不写，不要硬编。Greene 的原则：误读比不读
   更伤人。

## 第六部分：技术参考

### 宫位含义（Tompkins 标准 + Sasportas 发展含义 + Greene 8宫补充）
1宫(命宫): 自我形象、外貌 — Sasportas："人生探险的出发点，我们透过什么
   镜头看世界"
2宫(财帛): 收入、价值观 — Sasportas："欲念能量是强大而神秘的力量——
   我们渴望什么决定了我们吸引什么"
3宫(兄弟): 沟通、学习 — Sasportas："心智从身体中分化的过程"
4宫(田宅): 家庭、根脉 — Sasportas："自省意识的诞生"
5宫(子女): 恋爱、创造 — Sasportas："将自己区别于他人的独特冲动的表达"
6宫(工作): 日常工作、健康 — Sasportas："内在世界与外在形式的对应关系"
7宫(夫妻): 伴侣、合作 — Sasportas："'我'重新与'非我'连接"
8宫(疾厄): 共享资源、性、转化 — Sasportas："关系作为改变的催化剂";
   Greene："将死亡与遗产那种粗浅的解释是一种侮辱——这里有远比那复杂的东西"
9宫(迁移): 高等教育、哲学 — Sasportas："将生命理解为一段旅程"
10宫(官禄): 事业、社会地位 — Sasportas："个体融入社会的整合过程"
11宫(福德): 社交、理想 — Sasportas："超越自我认同的尝试"
12宫(玄秘): 潜意识、退隐 — Sasportas："回归原始统一的渴望"

### 相位容许度（综合现代标准，参考 Tompkins 体系）
合相&对冲：日月10° / 金水火8° / 土木天海冥6°
其他（四分/三分/六合/补八分）：日月8° / 金水火6° / 土木天海冥4-5°

### Greene Saturn 按元素解读
土星在水象（巨蟹/4宫 天蝎/8宫 双鱼/12宫）：情感封锁——感受力强但表达堵塞
土星在土象（金牛/2宫 处女/6宫 摩羯/10宫）：物质不安全感——过度依赖外部
   成就确认自我价值
土星在风象（双子/3宫 天秤/7宫 水瓶/11宫）：心智/社交隔阂——过度理性化情感
土星在火象（白羊/1宫 狮子/5宫 射手/9宫）：自我表达封锁——对独特性缺乏信心
