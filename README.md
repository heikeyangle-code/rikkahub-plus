# RikkaHub Plus — 命理 & 酒馆增强版

> 基于 [RikkaHub](https://github.com/rikkahub/rikkahub) 的深度定制分支（Android 原生 LLM 聊天客户端），
> 在保留原版全部能力的基础上，加入了命理排盘、SillyTavern 角色卡兼容、群聊、Agent 工具等增强。

## ✨ 本分支特色

### 🔮 命理引擎（mingli 工具）
- 现代西洋占星 / 传统西洋占星 / 印度占星（吠陀） / 深度古典占星
- 八字、紫微斗数、塔罗、雷诺曼
- 内置排盘引擎 + JavaScript/Python 自探索能力，支持行运、推运、返照等时间技法

### 🍺 酒馆（SillyTavern）兼容
- 角色卡 V2/V3 导入导出（PNG/JSON，字段无损）
- 世界书（Lorebook）：官方触发逻辑、分组、递归、粘性/冷却、预算、层级延迟
- 宏引擎 2.0（变量、条件、随机、时间等官方宏）
- 斜杠命令、人设（Persona）、导演备注（Author's Note）
- 群聊（多人角色自动接话）

### 🤖 Agent 能力
- 技能系统（SKILL.md）、MCP 服务器、Python/JS 引擎
- 文件 / Shell / 任务 / 计算器 / 数据库查询等本地工具
- 工作区沙箱、消息全文搜索（jieba 中文分词）

### 📱 原版能力全部保留
Material You、多提供商切换（OpenAI/DeepSeek/Claude/Gemini…）、流式输出、
对话分支、收藏、TTS/ASR、Web 服务端、备份等。
